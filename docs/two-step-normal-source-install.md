# Explicit A normal source installation

This source does not install services, declare financial epochs, change fees or
resume dispatch. Root-owned configuration and genuine source qualification are
required before the callback can be used.

The Python entry point is `simulator.two_step_normal_factory.build_collector`.
Pass the existing preserved Store, original boundary proposal, qualification
event sequence, exact public source configurations and qualified proof commands.
Use its return value as `Engine(..., financial_source_collector=collector)`.
For first opening call `collector.prepare_opening(...)` explicitly while paused;
this verifies a new source cut and records its readiness evidence, but does not
change the normal epoch, funding plan, envelope, Store budget or dispatch mode.
Recurring Engine observations call the same collector and retain the original
opening, actions, liabilities, costs and source history.

`target_configuration` has command (the original bounded forced SSH argv without
remote command), evidence_directory (private owned existing directory), timeout
(at most45 seconds). The reader appends only `financial-source <canonical UUID>`
and closes stdin. The TARGET dispatcher maps this to the32hex Store observation
nonce and the fixed root-owned source program. Literal native inventory wrappers
and all fee-history/source originals retain their actual byte hashes.

`member_configuration` has these exact operational values:

- helper_command: Python executable and pinned installed bank/fixture source.
- helper_sha256: the actual installed source SHA256.
- helper_evidence_root: the fixed private helper output parent.
- evidence_root: a distinct existing private composer output parent.
- chain_url: the existing loopback independent Core RPC URL.
- scoped_core_config: the existing0600 rpcuser/rpcpassword config FILE path;
  its values remain only in local memory. This is not a full wallet cookie.
- prepared_descriptors and prepared_descriptors_sha256: the immutable genuine
  all24 pure-derivation/fresh-generation manifest, containing no seed bodies.
- wallet_root: the existing actor wallet parent; only public descriptor/index
  and locked-outpoint SQL columns are read. Nonempty WAL requires a separately
  authenticated consistent private snapshot; no SDK wallet is opened.
- actor_member_ids: exact actor01–24 to immutable customer member IDs.
- bank_member_id, fixture_member_id, target_cln_member_id, backing_member_id:
  the actual declared member IDs, not aliases inferred from source replies.

`capture_configuration` contains the exact boundary SHA256, admitted driver
configuration SHA256 and actor_member_ids. Admission additionally binds the
actual target/member reader configurations by `reader_configuration_sha256`.
The qualification event's `capture_dependencies_sha256` includes target_reader,
member_reader, public_wallet_metadata, descriptor_scan and factory module hashes.
Its `member_source_sha256` is the composer module hash; `target_source_sha256`
is the actual installed TARGET source program hash. Core adapter/tool/native
fee/history qualification fields are defined in two-step-normal-collector.md.

The Financial helper stdout is only manifest_path/manifest_sha256. Its exact
nonce directory is fixed below helper_evidence_root; every named private file is
hash/size checked. Bank coverage derives from real bounded native descriptor,
UTXO, lock, transaction-history and scanning/pending source results. No reported
complete or discovery boolean grants coverage. Both CLN endpoints preserve raw
private originals, while public journal events contain only selected money and
identity fields; PSBTs and preimages are omitted.

Customer discovery uses actual single-External BDK descriptors and persisted
issued frontiers. The descriptor ID must equal SHA256 of the independently
derived index-zero script. Existing zero snapshots do not supply a birthday.
Current unspent outputs are scanned in bounded batches of at most16 descriptors,
independently checked through Core, with a separate complete matching-script
mempool activity check. All24 identities remain present, including permanent
absences and genuinely dormant future identities. A scan does not replace the
historical injection/cost/rights or source-provenance proofs.

A successful source capture is not readiness. The enclosing collector executes
actual qualified native Full/per-key proofs and verifies native policy/history,
R/F, current fee cash, all declared members, liabilities and whole-boundary
accounting before emitting financial_operating_readiness. Unsupported nonempty
round, pool, HTLC, offboard, settlement or nursery domains explicitly hold until
an actual resolver exists. Source refusal retains private partials and original
journal history. No fallback complete=true path exists.
