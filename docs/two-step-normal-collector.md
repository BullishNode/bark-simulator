The A normal collector is an installed Python dependency of the shared normal
financial hook. It reads authenticated private source records and executes the
admitted pure native proof tools. It opens no SDK wallets, signs nothing, and
does not declare an operating epoch, allocate money or resume dispatch.

`Collector(capture, admission_sequence, tools)` is the callback passed as
`Engine(..., financial_source_collector=collector)`. First opening instead uses
`await collector.prepare_opening(store, config, chain, snapshot, observation,
boundary, envelope, opening_declaration)`. That verifies the proposed first
opening and returns a readiness event sequence; it does not declare the boundary.
Once the first opening is admitted, the callback authenticates `recorded(store)`
and reconciles subsequent observations against its original assets. It never
requires `history()` to be rerun with live dispatch or a final epoch present.

The independent source qualification event `normal_financial_collector_qualified`
binds financial pins, each actual native executable hash, the adapter/capture/
fee/recovered/component module hashes, exact proof executable and command hashes,
the external policy SHA, native epoch/history/opening identity, recovery script/F,
rounds/watch treasury member IDs and original injection declaration hashes. A
source response cannot supply, change or replace that admission.

The admitted asynchronous `capture(store, config, chain, snapshot, observation)`
reads the current original frames and writes new public source/member/inventory
events. It returns:

* `source_sequence`: its new `normal_financial_source` event sequence.
* `inventory_sequences`: all declared treasury members, without omission.
* `raw_sql`, `raw_policy`, `raw_core`, `raw_rounds_inventory`: exact private bytes.
* `fee_history`: original root identity, policy identity bytes, index bytes,
  candidate files and, for an imported opening, certificate/digest bytes.

The source event carries the unchanged `source_observation`, actual identity and
binary hashes, financial pins, boundary ID, height/tip and current observation
time. `original_sha256` hashes the four buffers under `native_sql`, `policy`,
`core`, `rounds_inventory`; `fee_history_sha256` hashes the private byte-file
digest projection. It also carries `inventory_source_sequences`,
`member_source_hashes`, `rounds_member_id`, `watchman_member_id`, complete ordered
`flow_sequences`/`cost_sequences`, original `injection_declaration_hashes` and
exact public pending liabilities with original source event sequences.

Each `treasury_native_inventory_source` contains exact reported UTXOs/channels,
actual member identity/pins/tip/time, pending transactions, reserved outpoints and
discovery gaps. The two fee-wallet frames additionally retain their literal
`wallet_inventory` so eligibility can be checked against actual native known,
trusted, mature, confirmed and unreserved outputs. CLN members retain the actual
public `getinfo`, `listfunds`, `listpeerchannels` projections. Both owned channel
endpoints must cover the full channel amount, including owned reserves; cash and
funding are never counted twice. Descriptors and backing membership still pass
the existing independent treasury checks.

SQL uses a single read-only repeatable-read snapshot, exact thirty-table coverage
and count-equals-array-length checks. Named unsupported conditional, round, pool,
settlement, release and other domains hold while nonempty; no missing table means
zero work. This first adapter supports direct-root ordinary signed claims and
direct-root recovered backing. It is not a resolver for every later liability
type. Such extensions require their own source proofs before readiness can pass
with those rows present.

Every retained claim is rechecked through the pinned Full/path and per-key tools.
An expired or swept backing does not remove its customer liability. The recovered
helper follows each claim to its exact held root and confirmed native receipt.
Full native R plus distinct F encumbers the rounds cash pool once; customer
principal is not subtracted again as another cash hold. The native urgent floor
requires actual unreserved watch cash. All signed native candidate inputs are
excluded from available cash, and reserved inputs are never described as liquid.

The native fee verifier authenticates exact policy, SQL and retained journal
bytes. Original TOTAL, booked/remaining reservations, imported historical cost and
confirmed miner payments remain separate. A confirmed carrier must have its exact
once-only independent miner-cost event. Historical opening costs are retained
but excluded from the new treasury edge and new common budget debit. Actual new
costs, held client reservations and unpaid native reservations together must fit
the immutable outer budgets. No source response renews them.

The real conservative Core quote is reported even when it exceeds a quiet-path
ceiling. Existing per-operation preflight decides affordability, including the
separate urgent paths. The collector never silently substitutes a clamped quote.

Current source-unit controls use synthetic sources and Store fixtures. Native
proof execution, real transport authentication, exhaustive current discovery,
deployment admission, actual first opening and continuous financial qualification
must also pass before this source can authorize any live action.
